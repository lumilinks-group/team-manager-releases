# Team Manager

A simple Windows desktop app for keeping track of what each person in your team is working on, and the asks that are still open between you. Everything is stored on your own computer.

## Install

1. Open the **[latest release](https://github.com/lumilinks-group/team-manager-releases/releases/latest)** and download `Team-Manager-Setup-<version>.exe` from **Assets**.
2. Run it. It installs just for you, so you don't need admin rights.
3. If Windows shows *"Windows protected your PC"*, click **More info → Run anyway**. This appears because the app isn't code-signed yet.

## Updates

The app updates itself. New versions download in the background and install the next time you restart it. You'll see a **Restart to update** button when one is ready.

## Help

Open **⋯ → User guide** inside the app.
